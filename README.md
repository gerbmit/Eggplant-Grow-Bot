# 🍆 Eggplant Grow Bot

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&logo=python&logoColor=white)
![Telegram](https://img.shields.io/badge/Telegram_Bot-2CA5E0?style=flat-square&logo=telegram&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white)

Многофункциональный игровой Telegram-бот для групповых чатов. Классическая механика выращивания расширена полноценной экономикой, PvP-сражениями, боссами, мини-играми и системой достижений.

---

## ✨ Возможности

* 🌱 **Основная игра** — регулярный рост, случайные события и прокачка персонажа
* ⚔️ **Дуэли (`duel`)** — PvP-сражения между участниками чата
* 👹 **Боссы (`boss`)** — совместные битвы с боссами и награды за победу
* 🥷 **Кражи (`steal`)** — возможность рискнуть и стащить прогресс у других игроков
* 🎰 **Казино (`casino`)** — мини-игры на внутриигровые ресурсы
* 📦 **Аирдропы (`airdrop`)** — случайные раздачи и ивенты прямо в чате
* 🎁 **Бонусы (`bonus`)** — система регулярных наград
* 🛒 **Магазин и переводы (`shop`, `pay`)** — покупка улучшений и передача ресурсов другим игрокам
* 🏆 **Профиль, достижения и рейтинги (`profile`, `achievements`, `rating`, `global_top`)** — статистика игрока, ачивки, топ чата и глобальный рейтинг
* 🛡️ **Защита и администрирование (`middlewares`, `admin`)** — встроенный антифлуд (throttling), контроль типа чата и расширенная админ-панель

## 🚀 Быстрый запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/gerbmit/Eggplant-Grow-Bot.git
cd Eggplant-Grow-Bot
```

### 2. Создайте виртуальное окружение и установите зависимости
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройте конфигурацию
Укажите токен бота (полученный у [@BotFather](https://t.me/BotFather)) и ID администраторов в `config.py` (или в файле `.env`, если используете переменные окружения).

### 4. Запустите бота
```bash
python bot.py
```

## 📋 Основные команды

### 🎮 Команды для игроков (работают в группах)

#### 🌱 Основные
| Команда | Описание |
| :--- | :--- |
| `/start` | Регистрация и стартовое приветствие. |
| `/grow` | Попытка вырастить агрегат (кулдаун 12–17 часов, есть мини-события и баффы). |
| `/profile` | Досье игрока: звание, прогресс-бар, ранг, средний рост, активные баффы и достижения. |
| `/top` | Топ лучших игроков текущего чата. |

#### 💰 Экономика и бонусы
| Команда | Описание |
| :--- | :--- |
| `/shop` | Теневой рынок: покупка Щита, Стероидов, Капкана на вора, Приманки для Босса, Энергетика и Черного Ящика. |
| `/bonus` | Контрабанда: выбор 1 из 3 сундуков с призами, баффами или ловушками (кулдаун 16 часов). |
| `/pay [сумма / all]` | *(ответом на сообщение)* Перевести свои сантиметры другому игроку. |

#### 🎲 Мини-игры и PvP
| Команда | Описание |
| :--- | :--- |
| `/casino [сумма / all]` | Казино «Три топора»: слот-машина со ставками на сантиметры (выигрыши до х20). |
| `/duel [сумма / all]` | *(ответом на сообщение)* Вызвать другого игрока на дуэль насмерть. |
| `/steal` | *(ответом на сообщение)* Попытаться ограбить игрока (кулдаун 2 часа, минимум 30 см у обоих, срабатывает капкан). |
| `/fap` | *(можно ответом на сообщение)* Рулетка времени (кулдаун 9 минут): может ускорить или замедлить таймер `/grow`, а при неудаче — нанести травму (-1–3 см). |

#### 🦖 Рейд-боссы
| Команда | Описание |
| :--- | :--- |
| `/boss` | Призвать босса в чат (кулдаун 6 часов) или посмотреть ХП и топ урона по текущему боссу. |
| `/hit` | Атаковать активного босса (кулдаун 5 минут). |

#### 🥷 Тайные и глобальные (можно писать прямо в ЛС боту)
| Команда | Описание |
| :--- | :--- |
| `/admin` | Открыть справку админ-панели. |

| `/broadcast` | 📢 Запустить рассылку текста/фото/видео по всем группам. |

| `/bandrop [id]` | 🚫 Скрытно запретить игроку забирать аирдропы во всех чатах (покажет отмазку про шнурки). |
| `/unbandrop [id]` | ✅ Вернуть игроку возможность забирать аирдропы. |
| `/botstats` | 📊 Глобальная статистика бота (всего групп, игроков и общий размер). |

#### ⚙️ Локальные (пишутся в конкретном чате)
| Команда | Описание |
| :--- | :--- |
| `/give [id] [см]` | Выдать игроку сантиметры. |
| `/take [id] [см]` | Отрезать сантиметры у игрока. |
| `/givebuff [id] [щит/х2]` | Выдать Щит (`щит`) или Стероиды (`х2`). |
| `/reset [id]` | Полностью обнулить прогресс игрока в этом чате. |
| `/ban [id]` | Забанить игрока в этом чате. |
| `/unban [id]` | Разбанить игрока в этом чате. |
